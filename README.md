# 🚀 Space Shooters

A 2D space shooter game made from scratch using **C++** and **Raylib**.

## 🎮 Current Features

* 🚀 Player movement using **WASD**
* 👾 Multiple moving enemies
* 🔫 Shooting using **X**
* 💥 Bullet collision detection
* 🌌 Space background
* 🧱 Player screen boundaries

## 🛠️ Built With

* **C++**
* **Raylib**

## 📸 Current Progress

The game is currently in active development.

More mechanics and polish will be added as the project evolves.

## 🗺️ Planned Features

* Enemy destruction
* Multiple bullets
* Particle effects
* Score system
* Player health
* Game over / restart system
* Sound effects
* Better enemy AI
* UI and menus
